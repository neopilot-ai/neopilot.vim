# Upgrade Notes for v1.0-beta

This document outlines important considerations when upgrading to Neopilot v1.0-beta.

## General
- No breaking changes are introduced in this beta release from previous alpha/development versions.
- Users upgrading from very old (pre-alpha) versions may need to re-authenticate using `:Neopilot Auth`.

## Minimum Requirements
- **Vim**: 9.0.0185+ with text properties
- **Neovim**: 0.6.0+ with virtual text support

## Configuration Changes
- All existing `g:neopilot_` configurations should continue to work as expected.
- Refer to the `README.md` for updated configuration options and recommended settings.

## New Features
- The `README.md` details new features and commands available in this release. Please review it for the latest functionality.

If you encounter any issues during the upgrade process, please refer to the `TROUBLESHOOTING.md` (if available) or report them on the GitHub issues page.
